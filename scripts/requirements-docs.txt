# The HTML renderer behind specs/<version>/fluid-spec.html, pinned exactly.
#
# The rendered HTML is committed, and CI regenerates it to prove it is current
# (generate-docs.py --check), so the renderer is part of the build's input.
# Re-rendering the unchanged 0.7.2 schema with a later release than the one
# that produced the committed page rewrote its quote escaping throughout and
# added sections the earlier release had not rendered. generate-docs.py
# refuses to run with any other installed version of these packages.
#
# THIS FILE IS THE INPUT. Install from scripts/requirements-docs.lock, which
# holds these pins plus every transitive dependency, each with its hashes:
#
#   pip install --require-hashes -r scripts/requirements-docs.lock
#
# so that a package replaced on PyPI after the fact is refused rather than run.
# generate-docs.py --check fails if the two files disagree.
#
# Move a pin deliberately: bump it here, recompile the lock (from the repository
# root, with the Python version CI uses, 3.12, because the lock is resolved for
# the interpreter that runs pip-compile):
#
#   pip install pip-tools
#   pip-compile --generate-hashes --strip-extras \
#       --output-file=scripts/requirements-docs.lock scripts/requirements-docs.txt
#
# then run `python3 generate-docs.py`, and commit the regenerated specs/ in the
# same pull request.
